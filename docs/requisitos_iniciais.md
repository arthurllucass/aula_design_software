# Requisitos iniciais — legado

1. O sistema deve permitir inscrições em eventos.
2. Deve emitir ingressos.
3. Deve respeitar a capacidade do evento.
4. O pagamento deve funcionar corretamente.
5. Deve permitir diferentes tipos de ingresso.
6. Deve contratar fornecedores.
7. Deve realizar check-in.
8. Participantes devem receber notificações.
9. O sistema deve suportar muitos acessos.
10. Deve ser fácil integrar novos parceiros.

Os requisitos não possuem critérios de aceitação suficientes.
