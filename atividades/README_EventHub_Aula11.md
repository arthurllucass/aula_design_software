# EventHub — Aula 11

## Tema
Modelo de domínio, componentes e conectores

## Situação do projeto
O EventHub contém decisões e artefatos legados possivelmente incompletos ou inadequados ao conteúdo desta aula. O aluno deve analisar o estado atual antes de modificar.

## O que o aluno deve fazer
1. identificar classes conceituais e responsabilidades;
2. produzir CRC ou equivalente;
3. distinguir Evento, Local, Inscrição, Ingresso e Check-in de detalhes técnicos;
4. propor componentes e conectores.

## Dicas
- Nem toda classe é componente.
- Pagamento e QR Code são fronteiras externas.

## Evidências mínimas
- Issue `Aula 11`;
- branch sugerida `aula-11`;
- commits explicativos;
- README/Markdown com problema observado, alteração realizada e critério de aceitação;
- evidência de compilação/teste quando houver código;
- PR ou revisão equivalente quando aplicável.

## Prazo operacional
O trabalho deve começar em sala e ser concluído até o início da aula seguinte, salvo orientação diferente do professor.
